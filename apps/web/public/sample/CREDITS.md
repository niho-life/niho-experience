# 仮素材と掲載許諾済みのNIHO写真

オーナー判断（2026-10-20）で、写真の撮影前にテストサイトの見た目を確かめるため、ネットの無料素材を仮に置いている。本番公開の前に、仮素材を使う表示を残さない（`docs/release-acceptance.md`）。

- オーナー判断（2026-11-02）で、掲載元ページのコミュニティディナー写真8枚をExperience掲載に使う許可を得た。テストサイトでは `niho-cd-*.jpg` と `niho-dinner-*.jpg` の全8枚を使う。写真に写る第三者の肖像同意は未確認のため、本番公開前に確認する。建物外観 `niho-exterior.jpg` はP-01の公開ギャラリーには使わない（正確な集合場所は予約後に案内）。
- オーナー判断（2026-10-20、スマホの試作モックに見た目を合わせる）で、他のテスト体験では次を使う。
  - `niho-*.jpg`：NIHO kamakura が持つ自前の写真（リビング、建物の外観）。
  - `host-*.jpg`：ホストの顔。`host-takuya.jpg` はオーナー本人の写真（提供）。ほかは顔の代わりのストック写真（Unsplash）で本人ではないので、撮り直しで必ず差し替える。
  - `video/strip-calligraphy.mp4`：書道の動画（Pexels）。写っている人物はホスト本人ではない。
- 撮り直し前の表示であることは、ページ下部のプレビュー表記（プレビュー時だけ）で伝える。
