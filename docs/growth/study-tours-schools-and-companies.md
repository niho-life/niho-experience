# 学校・企業向けスタディツアー（調査・事業方針）

調査日：2026-11-14（日本時間）／関連：[鎌倉の体験をみんなで育てる事業方針](community-led-strategy.md)、[鎌倉の体験市場とNIHOの商品機会](kamakura-experience-market-opportunities.md)

> この文書は公開情報から作った**企画判断の材料**である。学校・企業・受け手との合意、商品・料金・開催の確定を意味しない。実在する学校・団体・事業者の名前は公開情報の根拠としてのみ記載し、NIHOとの提携や参加意思を示すものではない。金額の多くは検索で見つけた公開資料で、**本文を開いて確かめたもの（一次）**と**検索の要約だけのもの（要約）**を分けて書く。NIHOの試算・推測はそう明記する。

## 1. 結論（方針）

1. **売るのは「相談」ではなく「スタディツアー」。** 学校や企業の目的に合わせて、どんな切り口で、どんな人に会いに行くかを一緒に決め、事前の準備から当日の段取り・振り返りまでを一式で受ける。相談だけに値札を付けて売っている前例は、今回の調査では見つからなかった。お金が動いているのは、訪問・対話を含む一式である（リディラバのスタディツアー、大阪の町工場見学、南三陸町観光協会の企画費など。§4）。
2. **中心にあるのは「その切り口で語れる当事者・実践者に、直接会って話を聞く」こと。** 切り口は一つに決めない。探究学習、SDGs、キャリア教育、地域づくり、観光と暮らし、起業・小商い、海と環境、防災、リーダー研修、新規事業の探索、組織づくりなど、相手の目的に合わせて組み直す。同じ受け手の話でも、学校には学びの問いとして、企業には事業や組織のヒントとして届けられる。社会課題はその切り口の一つであり、そこに寄せすぎない。
3. **相手は、街の外から来る学校と企業。** 学校では、東京近郊から日帰りで来る中学・高校（とくに私立）を主に考える。鎌倉市内の学校はすでに街の中にいるので、この事業の対象にしない。東京の私立中の鎌倉への日帰りの校外学習は定番だが、寺社巡りが中心で、人に会う型は一部にとどまる（§3）。入口は「いつもの鎌倉の校外学習を、人に会う学びに変える」提案になる。
4. **値段の目安は1件10〜30万円（試算）。** 1人2,000〜4,000円×50〜160名、または企業の研修・視察の団体料金。リディラバは75名から催行し、料金は公開していない（§4）。年5件で売上100万円前後になる（§7）。学校の校外学習は学年ごとの毎年の行事なので、採用されると翌年も続きやすい。
5. **まずNIHO kamakuraが鎌倉・逗子・葉山を担い、型を作る。** 切り口の作り方、事前教材のひな形、見積・保険・当日の段取り、受け手への謝礼の決まりを型にし、ほかの街に拠点ができるたびに対応エリアを足す。営業と型はNIHO全体、届けるのは各拠点という分担にする（§8）。
6. **次に確かめることは「払うか」。** 検索では分からない。すでに鎌倉に来ている私立校の先生と、企業の研修担当に、1枚の提案（切り口・1日の流れ・料金）を見せて反応を聞く（§10）。

無料の窓口もある。東京観光財団は2026年度に中高生向けの観光学習の相談窓口（約1時間・無料）を開いたが、内容は生徒の観光プランへの意見交換で、訪問先の紹介や当日の段取りまでは書かれていない（[トラベルボイス 2026-07-02](https://www.travelvoice.jp/20260702-160081)）。企業の出前授業も無償の例が多い。「大人の話を聞く」こと自体には値段が付きにくく、値段が付くのは、目的に合う人を選び、会える段取りを整え、学びにつなげる一式の部分だと考える（推測）。

## 4. 近い事業と料金の実例

**リディラバのスタディツアー**がいちばん近い型である（一次：[公式](https://ridilover.jp/study-tour/)、2026-11-14に確認）。

- 中学・高校向けで、修学旅行・校外学習に使われる。所要は約6時間（現場の訪問 約2時間＋ワークショップ 約2時間）。
- 事前学習は独自の動画教材とツアーごとのワークシートで、先生向けの指導の手引きがあり、授業1〜2コマで学校が行う。
- 生徒75名から催行し、75名未満でも75名分を請求する。料金は公開されていない。
- 年60校以上が導入し、累計250校・6万人以上（2025年12月末）。地域は福島・東京・静岡〜神奈川・京都〜大阪・福岡・沖縄。鎌倉のツアーは検索では見つからなかった。
- 教育旅行の担当は社員4名と業務委託等4名の計8名（一次：[採用ページ](https://hrmos.co/pages/ridilover/jobs/2239910316986294272)）。
- テーマ（例：障がいのある人の「働く」、現代の「貧困」）を単位に売っている。

## 6. NIHOのスタディツアーの形（案）

- **事前**：オンラインの相談1回で、学びや研修の目的と切り口を決める。切り口ごとの事前教材（質問づくりのワークシート、先生・担当者向けの手引き）を渡す。
- **当日（約5〜6時間）**：受け手の現場を2〜3か所訪ねる。1か所に20〜40人のまとまりで訪ねる形と、5〜6人の班で訪ねる形を、人数と受け手の受け入れ方で選ぶ。160人の学年でも、まとまりで訪ねれば現場は4〜6か所で済む。
- **振り返り**：NIHOの拠点を集合・雨の日・荷物・ワークショップの場に使う。人数が拠点に入りきらない場合は、寺や公民館など地域の会場と組む。
- **事後**：発表や報告に使えるシートを渡す。
- **受け手の組を先に作る**：鎌倉・逗子・葉山の店主、作り手、漁業者、寺社、移住して仕事を始めた人、まちづくりの担い手、地元企業などから、切り口ごとに受け手の組を作っておく。学校・企業ごとにゼロから探さない。
- **受け手に必ず謝礼を払う**：継続的な無償の協力を前提にしない（[事業方針](community-led-strategy.md)と同じ考え方）。受け入れると決めた人のところへ順番に行く形は、混む通りで生徒が飛び込みで話を聞くより、店の負担も小さい。

## 7. 収支の目安（試算）

- 1人2,500円×80名＝1件20万円。年5件で売上100万円前後。
- 費用：受け手への謝礼（1か所1〜2万円×3〜4か所）、事前教材の制作（切り口ごとに初回だけ）。
- 手間：1件あたり30〜40時間（相談2回、下見、当日、事後）。学校の校外学習は5〜6月と10〜11月の平日に集まりやすい。
- 立ち上がり：1年目は1〜2件、年5件は2〜3年目の目標とみる。
- 学校の校外学習は学年ごとの毎年の行事なので、一度採用されると翌年も続きやすい。

以上はNIHOの試算で、学校・企業から得た見積や実績ではない。

## 8. 拠点を増やして対応エリアを広げる

リディラバも地域を並べて売っている（§4）。NIHOでは次の分担を考える。

| 担い手 | 役割 |
| --- | --- |
| NIHO全体 | 東京近郊の学校・企業への営業、切り口の作り方の型、事前教材のひな形、見積・保険・謝礼・当日の段取りの決まり、品質の基準 |
| 各拠点（まずNIHO kamakura：鎌倉・逗子・葉山） | その街の切り口と受け手の組、当日の案内と振り返りの場 |

営業がいちばん難しいので、そこをNIHO全体でまとめ、拠点は届けることに集中できるようにする。拠点の運営者にとっては、場を開くことから生まれる収入の柱の一つになる。

## 9. 法務・安全の確認事項

- **旅行業の登録**：観光庁と神奈川県の資料では、旅行サービス手配業は「旅行業者の依頼を受けて行う」運送・宿泊・通訳案内・免税店販売の手配に限られる（一次：[観光庁リーフレット](https://www.mlit.go.jp/kankocho/content/001970412.pdf)、[神奈川県の手引き](https://www.pref.kanagawa.jp/documents/3722/tehaigyou-tebiki.pdf)）。運送と宿泊を手配せず、訪問先の紹介と当日の段取りだけを学校・企業から受ける形は当たらないと読めるが、そう明記した公的なQ&Aは見つかっていない。始める前に神奈川県の担当窓口に確かめる。貸切バスや宿泊を一緒に手配するなら、旅行会社と組む。
- **保険**：NIHOとして賠償責任保険に入る。学校側の学校旅行総合保険の有無を見積の段階で確かめる（鎌倉ガイド協会は損害保険に未加入で、学校側の保険を求めている）。
- **未成年の受け入れ**：受け手と、当日の連絡・集合・解散のルールを事前に決める。

## 10. まだ分からないこと・聞いて確かめること

| 分からないこと | 誰に何を聞くか |
| --- | --- |
| 学校は払うか、いくらまでか | すでに鎌倉に来ている私立中高の先生2〜3人に、1枚の提案（切り口・1日の流れ・1人あたりの料金）を見せる |
| 学校で誰が決めるか、どの費目から払うか | 同じ先生に、学年主任・探究担当・事務のどこで決まるか、校外学習費から払えるかを聞く |
| 企業の研修予算と、地域に払う意思 | 企業の人事・研修担当、新規事業の担当に、地域で人に会う研修の予算と頻度を聞く |
| リディラバの料金 | 学校向けの資料請求・空き状況の照会で確かめる。神奈川で競合になるか、鎌倉の現場の担い手として組めるかも見る |
| 受け手の負担と謝礼の水準 | NIHOの会員の事業者に、受け入れの経験、謝礼があれば受けるか、繁忙期の限度を聞く |
| 旅行業の登録の要否 | 神奈川県の旅行業の担当窓口に、運送・宿泊を扱わない形を具体的に説明して聞く |
| 鎌倉に来る学校の数と時期 | 鎌倉市観光課・鎌倉市観光協会に、教育旅行の来訪の記録があるかを聞く |

NIHO Experience に学校・企業向けの掲載や見積の入口を足すかは、数件の実績を作った後に判断する。最初は1枚の提案と、メール・フォームでの受付で足りる。
