# 日本語サイトの読みもの（#154）

日本語サイトの `/ja/guides`（一覧）と `/ja/guides/<slug>`（記事）。親は #561。英語サイトの記事の表示・URL は変えない。

## 書き方と出し方

- 既存の記事の基盤を使う。`/write` で記事を作るとき、「記事を書く言語」に **日本語** を選ぶ（既定は英語）。日本語の記事は `content.language = "ja"` を持つ（保存の形は変わらず、migration は無い）。書く権限・写真の許諾・公開と停止は、英語の記事と同じ（記事の提供者の現在の OWNER）。
- 公開の検査は言語ごと。英語の記事は今までどおりラテン文字だけ。日本語の記事は、題名と本文に日本語（かな・漢字）があること。どちらも、言語の宣言、著者、カテゴリ、H2見出し、`[CONFIRM` の残りが無いこと、写真の許諾を確かめる。言語の宣言が無い記事は公開できない。
- 日本語の記事は**英語サイトに出ない**。英語の一覧・記事・sitemap・フッターの「Guides」・体験ページの関連記事・トップの読みものは、日本語の記事を除いて組む。日本語の記事の URL を英語サイトの `/guides/<slug>` で開くと 404。

## 日本語サイトの表示

- 一覧（`/ja/guides`）：カテゴリ（日本語名）・題名・リード・書いた人と公開日。記事が無いときは「読みものを準備しています」。
- 記事：題名、リード、書いた人（肩書）と公開日・更新日、カバー写真、この記事の内容（H2が2つ以上のとき）、本文、「この記事に出てくる体験」（書き手が下書きで関連づけた、日本語の原稿があり予約できる体験）、「この記事のことで、相談したいときは」（相談の入口。相談の flag が ON のとき）、書いた人。
- 直接リンクだけで公開した記事（UNLISTED）は、一覧に出ず、記事ページは noindex。
- 読み取りに失敗したときは、一覧は空、記事は 404（エラーで人の名前などを出さない）。

## まだ無いもの

- 記事そのもの。最初の記事は、商品と実際に行った体験に合わせて、書き手が `/write` で書く（行っていない企画を実績として書かない）。
- 日本語の記事の構造化データ（sitemap は、公開記事が1本以上のとき `/ja/guides` と各記事を載せる。[seo.md](seo.md)）。トップ（#563）に数本を並べる部分。記事の中から人（#564）へのリンク。
- 英語の記事との hreflang の対（日本語の記事は英語の記事の翻訳ではないので、対にしない）。
