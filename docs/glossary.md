# 用語集

オーナー確定：2026-11-26（#681）

ホスト画面・公開画面・メールでは、同じものを同じ呼び方で表す。これから書く仕様文書・Issue・PRもこの用語に従う。既存の文書はこのIssueでは書き換えない。

## 基本用語

| 呼び方 | 定義 | 例 | コード上の名前 |
| --- | --- | --- | --- |
| ホスト | 体験を提供する単位。個人または団体で、体験・予約・売上・受取口座が属し、旅行者に見せる名前になる | NIHO kamakura、志龍 | provider（`providerKind`） |
| 販売者 | ホストの契約とお金の名義。特定商取引法の表示に出る。ホスト1つに1つ | パナソニックホールディングス株式会社 | seller（`sellerDisplayName`、販売者情報） |
| 代理受領 | 旅行者の代金を、販売者（ホスト）に代わって NIHO が受け取り、体験のあとにホストへ送る方法。「サポート 15%（NIHO が代金を受け取る）」。受付に受取口座は要らず、送金までに要る | — | `AGENT_15`（`sellerParty=PROVIDER`、`salesKindOf`）、`provider_agent_sales_consents` |
| メンバー | ホストに参加している人 | スタッフ、一緒に運営する人 | `provider_memberships` |
| オーナー | メンバーのうちの責任者。原稿・料金・公開、販売者情報、受取口座、売上、メンバーの追加と解除、取消・返金を扱える | ホストの責任者 | `OWNER` |
| メンバー（役割名なし） | 開催枠の編集、予約の確認、予約者への返信ができるメンバー | 一緒に予約対応をする人 | `COHOST` |
| 体験ごとのメンバー | 決まった体験の開催枠だけを扱う人 | 特定の体験の開催担当 | `OPERATOR`（商品限定運営者） |
| NIHO アカウント | 人がログインするためのアカウント。1人が複数のホストのメンバーになれる | ホスト画面へのログイン | host account（`hst_`）と NIHO identity |

個人のホストは、ホスト・本人・オーナーが同じ人を指す。画面を操作できる範囲（役割）と、旅行者向けに紹介を公開するかは別に扱う。メンバー全員が旅行者向けに紹介されるとは限らない。

## 画面で使う言葉

| 現在または旧来の呼び方 | 画面・メールで使う呼び方 |
| --- | --- |
| 提供者、事業者、担い手、迎える人 | ホスト |
| 共同ホスト、サブホスト | メンバー |
| 運営チーム、運営メンバー | メンバー |
| 商品運営者 | 体験ごとのメンバー |
| ホストアカウント | NIHO アカウント |
| 種別の「店舗・事業者」 | 団体・お店 |

文中では、置き換えた後も自然な日本語にする（例：「この提供者の運営メンバー」ではなく「このホストのメンバー」）。同じ `COHOST` を画面やメールによって「共同ホスト」「サブホスト」と呼び分けない。

## 用語を混同しないための決まり

- `EDITOR` の「編集者」と `VIEWER` の「閲覧者」は旧経路の役割名として維持する。現在の画面から追加できる `COHOST` の表示名には使わない。
- 「街の人」は `/ja/people` の公開人物一覧の名前として使う。メンバーの役割名にはしない。
- 法的な表示にある「販売事業者」と規約名の「提供者規約」はそのまま使う。
- 旅行者向け英語の対応語は Host／Seller／team。ホスト画面は日本語で表示する。
- コード上の識別子、DB・API のフィールド名、URL は変更しない。表示用語との対応は上の表のとおり。
