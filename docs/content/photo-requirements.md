# 写真の必要条件

最終更新：2026-10-19（担当3）。体験ページの写真は、人・手仕事・食卓・土地の空気が伝わることを優先する（[design-brief.md](../design-brief.md)）。

## 共通要件

| 項目 | 要件 |
| --- | --- |
| 枚数 | 1商品6枚以上、目安8〜12枚。タイムラインの各段階に1枚ずつ使えると望ましい |
| 内容 | その体験を実際に撮った写真。ストック写真、生成画像、別の体験の写真を実際の様子として使わない |
| サイズ | 長辺2400px以上（メイン写真）、その他は長辺1600px以上 |
| 構図 | メイン写真は3:2で撮り、4:5と1:1に切り抜いても主題が残るよう中央に余白を持たせる。縦位置も数枚含める |
| 形式 | JPEGまたはHEICの元データ。sRGB。透かし・文字入れ・枠なし |
| 明るさ | 自然光か明るい室内。食べ物と手元にピントが合っている |
| 代替テキスト | 1枚ごとに英語で、写っている内容を1文で書く。例：Two guests and a host slicing vegetables at the NIHO kitchen counter |

## 権利と同意

| 確認事項 | 記録先 |
| --- | --- |
| 撮影者と著作権者 | 非公開台帳 |
| 利用範囲：niho-experience、NIHOapp、NIHO公式サイト、OTA、SNS、広告のどれに使えるか | 非公開台帳。範囲外の場所へ使わない |
| 利用期間とクレジット表記の要否 | 非公開台帳 |
| 顔が分かる人の掲載同意。未成年は保護者の同意 | 同意書の原本は非公開保管先。リポに置かない |
| 寺社・店舗など撮影場所の撮影・掲載許可 | 非公開台帳 |

- 同意のない人が写っている場合は、使わないか、人物が特定できない写真に差し替える。ぼかし処理を前提にしない。
- 動画（YouTube の長尺、Shorts・Reels）も同じ表で確認する。利用範囲には媒体ごとに「長尺からの切り出し」「声と字幕」「サムネイルへの顔の使用」を含め、非公開台帳に記録する（[#152](https://github.com/niho-life/niho-experience/issues/152)）。
- 他の予約サイトに載っている写真は、そのサイトや撮影者が権利を持つ場合がある。提供者が権利を持つと確認できたものだけ使う。
- 既存のNIHOapp企画ページと公式サイトの写真も、新サイトとOTA・広告で使えるかを確認してから使う。

## 商品別の撮影リスト

### P-01 Community Dinner

1. メイン：長いテーブルで料理を囲み、ホストと参加者が話している引きの写真
2. キッチンで一緒に調理している手元
3. 季節の料理の寄り（毎回同じとは限らないため、季節が分かる説明を添える）
4. ホストの人物写真（各ホストの同意を取ったもの）
5. ウェルカムドリンクの場面
6. リビングの雰囲気（本棚、ソファ、絨毯）
7. 建物の外観と、使用する側面入口・NIHOの看板（道案内用）
8. 鎌倉駅西口から建物までの目印

### P-02 Coffee roasting

1. メイン：焙煎機の前で豆の色や音を確かめている場面
2. 生豆と焙煎後の豆の比較
3. スマートフォンで焙煎を設定する手元
4. 冷却中の豆
5. 淹れたコーヒーを注ぐ場面
6. 持ち帰り用に袋詰めした豆

### P-03 坐禅と法話

1. メイン：堂内または境内で坐禅をしている場面（撮影が許される場所）
2. 境内の景色、季節の植物
3. 法話の場面（僧侶の掲載同意があるもの）
4. 坐禅の姿勢・椅子での参加の様子（椅子を用意できる場合）
5. 案内・ガイドの場面

寺院の撮影規則を優先し、撮影できない場所の写真を求めない。

### P-04 器の修理

1. メイン：作り手が器を修理している手元
2. 修理前と修理後の器
3. 使う材料と道具
4. 参加者が作業している様子
5. 作り手の人物写真

### P-05 書道

1. メイン：筆で書いている瞬間
2. 道具（筆、墨、紙）
3. 作り手が手本を書く様子
4. 参加者が作品を持っている様子（同意のあるもの）
5. 作業の場所の雰囲気
